### 2.4. Ubiquitous Language

En esta sección se presenta el glosario de términos propios del dominio de negocio (área de salud y enfermería) para evitar ambigüedades y mantener una comunicación estandarizada entre todos los miembros del equipo y los stakeholders, tal como propone el modelo de *Domain-Driven Design*. 

| Término en Inglés | Equivalente en Español | Definición (Dominio de negocio) |
| :--- | :--- | :--- |
| **Shift** | Turno | Período de tiempo asignado en el que el personal de enfermería cumple con sus labores asistenciales en la clínica. |
| **Handoff / Handover** | Traspaso de turno | Proceso de transferencia de información, responsabilidad y autoridad sobre los pacientes de un turno saliente a un turno entrante. |
| **Vital Signs** | Signos vitales | Mediciones fisiológicas fundamentales (presión arterial, frecuencia cardíaca, temperatura, etc.) que indican el estado de salud del paciente. |
| **SBAR** | SBAR (Situación, Antecedentes, Evaluación, Recomendación) | Metodología estructurada de comunicación estandarizada utilizada para compartir información crítica del paciente entre el personal de salud. |
| **Alert** | Alerta / Notificación clínica | Aviso emitido cuando un paciente presenta una novedad, evento adverso o cuando una tarea prioritaria requiere atención inmediata. |
| **Ward / Department** | Área clínica / Pabellón | Sección física y administrativa dentro de la clínica donde los pacientes son atendidos (ej. Hospitalización, UCI, Emergencia). |
| **EHR (Electronic Health Record)** | Historia Clínica Electrónica | Sistema integral de la clínica que contiene el registro médico completo de los pacientes. Nurse Pulse complementa y no reemplaza este sistema. |
